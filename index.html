Что именно предлагаем

Не интернет-магазин и не скидочную систему. Сильная сторона сети уже в цене, поэтому задача проекта — сделать выбор быстрее, список вкусов актуальнее, а работу сотрудников спокойнее.

01

Вкусокарта в Telegram

Клиент выбирает точку, ищет вкус и смотрит информацию для ознакомления перед покупкой в офлайн-магазине.

02

Админка для команды

Сотрудники обновляют позиции, скрывают закончившиеся вкусы и отмечают наличие по каждой точке.

03

Страница сети

Адреса, режим работы, маршруты, ссылки на VK и Telegram, QR-код на бот и аккуратная 18+ подача.

Функции бота

Первый запуск можно сделать компактным, но сразу полезным для покупателей, продавцов и владельца.

Для покупателей

  • Подтверждение возраста 18+.
  • Выбор одной из 3 точек.
  • Поиск по названию, бренду и описанию.
  • Фильтры по вкусу, крепости, объему и холодку.
  • Контакты, режим работы и маршрут до магазина.

Для сотрудников

  • Добавление и редактирование позиций.
  • Отметка наличия по точкам.
  • Скрытие закончившихся позиций.
  • Загрузка ассортимента из таблицы.
  • Быстрый поиск ответа на вопрос клиента.

Как это работает в магазине

QR-код можно разместить на стойке, рядом с текущими распечатками или в Telegram-канале.

1

Клиент сканирует QR

Открывает бот с актуальной вкусокартой.

2

Выбирает точку

Наличие показывается по конкретному магазину.

3

Ищет вкус

Использует поиск или фильтры по параметрам.

4

Обращается к продавцу

Покупка происходит только в офлайн-точке.

MVP за 3-4 недели

Первый этап запускает рабочий инструмент, который можно сразу проверить на всех трех магазинах.

Входит в запуск

  • Telegram-бот с возрастным экраном.
  • Каталог вкусов, поиск и базовые фильтры.
  • Наличие по 3 точкам.
  • Админка для ассортимента.
  • Загрузка из таблицы.
  • Страница сети с адресами и ссылками.

Можно добавить позже

  • Расширенную аналитику поисковых запросов.
  • Импорт из учетной системы.
  • Отдельный режим продавца.
  • Автогенерацию печатной вкусокарты.
  • Настройку карточек в Яндекс Картах и 2ГИС.

Юридически аккуратный подход

Проект позиционируется как информационный сервис для офлайн-магазинов, а не как дистанционная продажа.

В проекте есть

  • Возрастной экран 18+.
  • Информация об офлайн-точках.
  • Справочный каталог для ознакомления.
  • Админка для актуальности данных.

В проекте нет

  • Корзины и онлайн-оплаты.
  • Доставки и оформления заказа.
  • Кнопок «купить» или «заказать».
  • Агрессивных рекламных формулировок.

Формулировки интерфейса можно дополнительно согласовать с юристом или ответственным сотрудником сети перед запуском.
