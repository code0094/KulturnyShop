# Деловое предложение для сети «Культурный шоп»

## Интерактивная вкусокарта и официальный цифровой сервис для 3 магазинов в Нижнем Новгороде

Здравствуйте!

Мы предлагаем сделать для сети «Культурный шоп» не интернет-магазин, а безопасный и полезный цифровой сервис для офлайн-точек: Telegram-бот с актуальной вкусокартой, простой админкой для сотрудников и страницей сети с адресами магазинов.

Главная идея: заменить бумажные распечатки со вкусами на удобный бот, где покупатель или продавец быстро находит нужный вкус, крепость, бренд и наличие по конкретной точке.

## Почему это актуально

Сейчас ассортимент живет на бумаге и в переписках:

- распечатки устаревают;
- список вкусов сложно быстро обновлять;
- покупателям приходится спрашивать продавца даже по простым вопросам;
- у разных точек может отличаться наличие;
- новым клиентам не всегда понятно, где ближайший магазин и как с ним связаться.

При этом у «Культурного шопа» уже есть сильное преимущество: доступные цены. Поэтому мы не предлагаем бонусную или скидочную систему, которая может съедать маржу. Вместо этого мы предлагаем улучшить удобство, скорость выбора и управляемость ассортимента.

## Что предлагаем сделать

### 1. Telegram-бот «Вкусокарта»

Бот показывает актуальный ассортимент для ознакомления в офлайн-магазине.

Функции:

- подтверждение возраста 18+;
- выбор одной из 3 точек;
- каталог вкусов по категориям;
- поиск по названию, бренду и описанию;
- фильтры по вкусу, крепости, объему, бренду, холодку;
- карточка позиции с описанием и наличием по точкам;
- быстрые ответы на частые вопросы;
- контакты и маршрут до магазина.

Важно: бот не является интернет-магазином. В нем нет корзины, онлайн-оплаты, доставки или кнопки «купить».

### 2. Админка для сотрудников

Простая панель, где сотрудники смогут обновлять вкусокарту без разработчиков.

Функции:

- добавление и редактирование позиций;
- скрытие закончившихся позиций;
- отметка наличия по каждой точке;
- загрузка ассортимента из таблицы;
- управление адресами и режимом работы магазинов;
- роли для владельца и сотрудников.

### 3. Страница сети

Официальная страница с базовой информацией:

- название сети;
- 18+ предупреждение;
- адреса 3 магазинов;
- режим работы;
- карты и маршруты;
- ссылки на VK и Telegram;
- QR-код на бот;
- юридически аккуратная формулировка без онлайн-продаж.

## Как это будет работать в магазине

1. На стойке размещается QR-код: «Актуальная вкусокарта 18+».
2. Клиент открывает Telegram-бота.
3. Выбирает нужный магазин.
4. Ищет вкус или использует фильтры.
5. Видит подходящие варианты и уточняет покупку у продавца в офлайн-точке.

Для продавца это тоже удобно: можно быстро найти ответ на вопрос клиента, не листая распечатки и не вспоминая весь ассортимент.

## MVP: первый этап

Состав первого запуска:

- Telegram-бот с возрастным экраном;
- выбор магазина;
- каталог вкусов;
- поиск;
- базовые фильтры;
- наличие по 3 точкам;
- админка для обновления ассортимента;
- загрузка из таблицы;
- страница сети с адресами и ссылками;
- QR-код для размещения в магазинах.

Ориентировочный срок: 3-4 недели.

## Стоимость

Базовый MVP: 180 000 - 300 000 рублей.

Точная стоимость зависит от:

- количества позиций в ассортименте;
- сложности фильтров;
- необходимости загрузки из текущих таблиц;
- состава админки;
- дополнительных интеграций.

Поддержка после запуска: 20 000 - 40 000 рублей в месяц.

В поддержку может входить:

- хостинг и технический мониторинг;
- небольшие правки;
- помощь с обновлением данных;
- резервные копии;
- консультации сотрудников;
- развитие функциональности.

## Что можно добавить позже

- расширенная аналитика по популярным запросам;
- импорт из учетной системы;
- отдельный режим для продавца;
- автоматическая генерация печатной вкусокарты из базы;
- страницы для каждой точки;
- улучшение карточек в Яндекс Картах, 2ГИС и других справочниках;
- интеграция с VK или Telegram-каналом для сервисных уведомлений.

## Юридически аккуратный подход

Мы предлагаем информационный сервис для офлайн-магазинов, а не дистанционную продажу.

В проекте не будет:

- корзины;
- онлайн-оплаты;
- доставки;
- оформления заказа через сайт или бот;
- рекламных обещаний, которые могут нарушать ограничения по никотинсодержащей продукции.

Формулировки и интерфейс можно дополнительно согласовать с юристом или ответственным сотрудником сети.

## Результат для бизнеса

После запуска у сети появится:

- актуальная цифровая вкусокарта вместо бумажных распечаток;
- единая база ассортимента по 3 точкам;
- удобный инструмент для продавцов;
- более быстрый выбор для покупателей;
- официальная страница сети;
- понятная основа для дальнейшей автоматизации.

Мы можем начать с небольшого MVP, быстро запустить его на одной или всех трех точках, а затем развивать проект по фактическим потребностям магазина.
