# Деловое предложение для сети «Культурный шоп»

## Варианты цифрового развития для 3 офлайн-магазинов в Нижнем Новгороде

Здравствуйте!

Мы предлагаем рассмотреть несколько цифровых решений для сети «Культурный шоп». Это не интернет-магазин и не одна конкретная услуга, а набор понятных модулей, из которых можно выбрать подходящий первый этап: официальный сайт, Telegram-бот, интерактивную вкусокарту, админку для сотрудников и дальнейшую автоматизацию.

Главная задача — сделать сеть удобнее для покупателей и проще в ежедневном управлении, не ломая текущую сильную сторону магазина: доступные цены.

## Почему это может быть полезно

Сейчас у сети есть VK и Telegram, но часть процессов остается ручной:

- покупатели ищут адреса, режим работы и контакты в разных местах;
- актуальные вкусы живут на бумажных распечатках;
- списки ассортимента приходится перепечатывать и обновлять вручную;
- наличие может отличаться по 3 точкам;
- продавцы тратят время на повторяющиеся вопросы;
- нет единого цифрового инструмента для всех точек сети.

Мы не предлагаем бонусную систему как основной продукт, потому что при низких ценах она может съедать маржу. Вместо этого предлагаем решения, которые улучшают удобство, скорость выбора, актуальность информации и работу сотрудников.

## Возможные направления

### Вариант 1. Официальная страница сети 18+

Небольшой сайт-визитка для доверия и навигации.

Что входит:

- адреса 3 магазинов;
- режим работы;
- карты и маршруты;
- ссылки на VK и Telegram;
- возрастной дисклеймер 18+;
- юридически аккуратные формулировки;
- QR-код на Telegram-бот, если он будет запущен.

Зачем это нужно:

- покупателю проще найти ближайшую точку;
- у сети появляется официальный адрес в интернете;
- можно использовать ссылку в карточках Яндекс Карт, 2ГИС, Telegram и VK.

### Вариант 2. Telegram-бот для клиентов

Бот как удобный справочник по сети.

Что может уметь:

- подтверждение возраста 18+;
- выбор ближайшего магазина;
- режим работы и контакты;
- маршрут до точки;
- ответы на частые вопросы;
- переходы в VK и Telegram;
- сервисные объявления без онлайн-продажи.

Зачем это нужно:

- меньше одинаковых вопросов в личку;
- клиент быстрее находит нужную точку;
- сеть выглядит более собранной и современной.

### Вариант 3. Интерактивная вкусокарта

Самый сильный первый продукт, потому что он заменяет бумажные распечатки со вкусами.

Что входит:

- каталог вкусов в Telegram-боте;
- выбор одной из 3 точек;
- поиск по названию, бренду и описанию;
- фильтры по вкусу, крепости, объему, бренду, холодку;
- карточка позиции с описанием и наличием по точкам;
- QR-код для размещения в магазине;
- режим быстрого поиска для продавца.

Важно: это справочный каталог для ознакомления в офлайн-магазине, а не интернет-магазин. В нем нет корзины, онлайн-оплаты, доставки или кнопки «купить».

### Вариант 4. Админка для команды

Панель управления, чтобы данные можно было менять без разработчиков.

Что входит:

- добавление и редактирование позиций;
- скрытие закончившихся позиций;
- отметка наличия по каждой точке;
- загрузка ассортимента из таблицы;
- управление адресами и графиком работы;
- роли для команды;

Зачем это нужно:

- данные остаются актуальными;
- не нужно каждый раз просить разработчиков поправить список;
- появляется единый инструмент по 3 магазинам.

### Вариант 5. Локальное присутствие и карточки организаций

Настройка и приведение к единому виду карточек сети в справочниках.

Что можно сделать:

- проверить карточки в Яндекс Картах и 2ГИС;
- привести к одному виду адреса, часы, контакты и ссылки;
- добавить фотографии и описание;
- разместить ссылку на сайт или бот;
- подготовить QR-материалы для точек.

Зачем это нужно:

- новых клиентов проще довести до магазина;
- меньше путаницы с графиком и адресами;
- сеть выглядит аккуратнее в локальном поиске.

## Рекомендуемый первый этап

Мы предлагаем начать с MVP, который быстро дает пользу и не требует перестраивать бизнес-процессы:

**Официальная страница сети + Telegram-бот + интерактивная вкусокарта.**

В состав первого запуска:

- сайт-страница с 18+ предупреждением;
- адреса, режим работы и контакты 3 магазинов;
- Telegram-бот с возрастным экраном;
- выбор магазина;
- каталог вкусов;
- поиск и базовые фильтры;
- наличие по точкам;
- простая админка для обновления ассортимента;
- загрузка из таблицы;
- QR-код для размещения в магазинах.

Ориентировочный срок: 3-4 недели.

## Пакеты работ

### Пакет 1. «Официальное присутствие»

Для быстрого и недорогого старта.

Состав:

- сайт-страница сети;
- адреса 3 точек;
- карты, контакты и график;
- ссылки на VK и Telegram;
- базовая подготовка к GitHub Pages или хостингу.

Ориентир: 25 000 - 45 000 рублей.

### Пакет 2. «Бот-справочник»

Для удобной навигации и снижения нагрузки на продавцов.

Состав:

- все из пакета 1;
- Telegram-бот 18+;
- выбор магазина;
- режим работы, контакты, маршруты;
- FAQ;
- сервисные сообщения.

Ориентир: 45 000 - 80 000 рублей.

### Пакет 3. «Вкусокарта»

Оптимальный первый коммерческий запуск.

Состав:

- сайт-страница;
- Telegram-бот;
- каталог вкусов;
- поиск и фильтры;
- наличие по 3 точкам;
- админка для ассортимента;
- загрузка из таблицы;
- QR-коды для магазинов.

Ориентир: 80 000 - 150 000 рублей.

### Пакет 4. «Цифровая система сети»

Для развития после MVP.

Состав:

- расширенная админка;
- роли сотрудников;
- аналитика по запросам и популярным вкусам;
- импорт из учетной системы;
- автогенерация печатной вкусокарты;
- интеграции с VK, Telegram или внутренними таблицами.

Ориентир: от 150 000 рублей, после уточнения интеграций.

## Поддержка после запуска

Ориентир: 8 000 - 20 000 рублей в месяц.

В поддержку может входить:

- хостинг и технический мониторинг;
- резервные копии;
- небольшие правки;
- помощь с обновлением данных;
- консультации сотрудников;
- развитие функциональности;
- контроль корректной работы бота и сайта.

## Юридически аккуратный подход

Мы предлагаем информационные сервисы для офлайн-магазинов, а не дистанционную продажу.

В проекте не будет:

- корзины;
- онлайн-оплаты;
- доставки;
- оформления заказа через сайт или бот;
- кнопок «купить» или «заказать»;
- агрессивных рекламных формулировок.

Формулировки и интерфейс можно дополнительно согласовать с юристом или ответственным сотрудником сети.

## Что получит бизнес

В зависимости от выбранного пакета сеть может получить:

- официальный сайт для 3 точек;
- Telegram-бот для клиентов;
- цифровую вкусокарту вместо бумажных распечаток;
- единую базу ассортимента;
- быстрый поиск вкусов для покупателей и продавцов;
- админку для сотрудников;
- аккуратное локальное присутствие в картах;
- основу для дальнейшей автоматизации.

Мы предлагаем начать с того варианта, который даст максимальную пользу без лишней сложности, а затем развивать систему по фактическим потребностям магазинов.
